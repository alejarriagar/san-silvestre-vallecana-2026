# Preparación San Silvestre Vallecana 2026

Aplicación web local en Python y Streamlit para planificar, registrar y analizar la preparación para la San Silvestre Vallecana 2026.

## Objetivo deportivo

- Competición principal: San Silvestre Vallecana, 31 de diciembre de 2026.
- Distancia: 10 km.
- Objetivo inicial: bajar de 50:00.
- Ritmo de referencia: 4:59 min/km.

## Funcionalidades previstas

- Perfil deportivo editable.
- Plan semanal y mensual de entrenamiento.
- Registro manual de carrera, gimnasio, jiu-jitsu, bicicleta y descanso.
- Importación de CSV y Excel.
- Registro de competiciones.
- Seguimiento de carga, sueño, fatiga y dolor de rodilla.
- Gráficos y estadísticas deportivas.
- Reglas deterministas de adaptación del plan.
- Panel de entrenador con modo demo e integración opcional con LLM.
